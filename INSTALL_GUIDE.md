# SMSLY Hosting - Installation Guide

Deploy your own PaaS in under 2 minutes! 🚀

---

## ⚡ One-Line Install (Recommended)

Run this single command on a fresh Ubuntu 22.04+ server:

```bash
curl -fsSL https://raw.githubusercontent.com/SMSLYCLOUD/smsly-hosting/main/install-v2.sh | sudo bash
```

This script automates everything:
1.  **Dependencies:** Installs Docker, Python, OpenSSL.
2.  **Security:** Generates cryptographically secure `SECRET_KEY` and `FIELD_ENCRYPTION_KEY` automatically.
3.  **Deployment:** Builds and starts the full stack (Django, Next.js, Postgres, Redis, Celery).

---

## 🛠️ Manual Installation

If you prefer to control the process:

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/SMSLYCLOUD/smsly-hosting.git
    cd smsly-hosting
    ```

2.  **Run the Installer**
    The installer is smart enough to detect it's running from the repo root.
    ```bash
    sudo ./install-v2.sh
    ```
    *Follow the prompts to set your Domain and Email for SSL.*

---

## 🔑 Key Configuration (Behind the Scenes)

The installer automatically handles the critical encryption keys required for the backend to function. It updates your `.env` file with:

```bash
# Generated by install-v2.sh
FIELD_ENCRYPTION_KEY=<32-byte-url-safe-base64-key>
SECRET_KEY=<50-char-random-string>
```

> **Warning:** Do not lose the `FIELD_ENCRYPTION_KEY` once you start adding services. It decrypts sensitive data in your database.

## 🐛 Troubleshooting

**Build Errors?**
If you encounter frontend build errors locally, ensure dependencies are clean:
```bash
cd frontend
rm -rf .next node_modules package-lock.json
npm install
npm run build
```

**Startup Crash?**
If the backend container crashes with `ImproperlyConfigured: FIELD_ENCRYPTION_KEY...`, re-run `./install-v2.sh` to regenerate the missing key in your `.env` file.
