# Serverless Functions (Hot Functions)

CloudNeuron supports serverless code deployments by dynamically wrapping functions in lightweight Node.js or Python containers.

## Runtime Isolation
- Autogenerated `Dockerfile` templates are constrained to unprivileged, non-root users (`node` or `function_user`) to prevent host-escape if the micro-container is compromised.
- Function deployments flow through the standard deployment pipeline, inheriting rollback and backup support.
