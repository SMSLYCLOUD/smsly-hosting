# SMSly Hosting - Installation Guide

Deploy your own PaaS in under 2 minutes! 🚀

---

## ⚡ One-Line Install (Recommended)

**Full automatic mode** — no prompts, just deploy:

```bash
curl -fsSL https://raw.githubusercontent.com/SMSLYCLOUD/smsly-hosting/main/scripts/quick-install.sh | sudo bash -s -- --auto --domain=hosting.yoursite.com --email=admin@yoursite.com
```

**Interactive mode** — prompts for configuration:

```bash
curl -fsSL https://raw.githubusercontent.com/SMSLYCLOUD/smsly-hosting/main/scripts/quick-install.sh | sudo bash
```

> [!TIP]
> The installer will: clone repo → install Docker → configure nginx + SSL → start all services → run migrations. Done in ~2 minutes!

## 1. Control Plane Installation

### Manual Install

```bash
# Clone repository
git clone https://github.com/SMSLYCLOUD/smsly-hosting.git
cd smsly-hosting

# Run installer
chmod +x scripts/install-control-plane.sh
sudo ./scripts/install-control-plane.sh
```

### What the Installer Does

1. ✅ Updates system packages
2. ✅ Configures UFW firewall (SSH, HTTP, HTTPS, K8s API)
3. ✅ Enables fail2ban for SSH protection
4. ✅ Installs Docker Engine & Compose
5. ✅ Generates secure encryption keys
6. ✅ Creates production `.env` file
7. ✅ Configures Nginx reverse proxy with rate limiting
8. ✅ Obtains SSL certificate via Let's Encrypt
9. ✅ Starts all Docker services
10. ✅ Runs database migrations

### Configuration Prompts

| Prompt | Example | Description |
|--------|---------|-------------|
| Domain Name | `hosting.example.com` | Your public domain |
| Admin Email | `admin@example.com` | For SSL cert notifications |
| Enable SMSLY? | `y` | Enable SMS/Voice alerts |
| SMSLY API Key | `sk_...` | Internal service key |
| Alert Phone | `+1234567890` | E.164 format number |

## 2. Worker Node Installation

Worker Nodes run your users' applications using K3s (lightweight Kubernetes).

### Quick Install

```bash
# SSH into your worker VPS
ssh root@<worker-ip>

# Download and run
curl -sL https://raw.githubusercontent.com/SMSLYCLOUD/smsly-hosting/main/scripts/install-worker-node.sh | sudo bash
```

### What the Installer Does

1. ✅ Configures firewall for K8s ports
2. ✅ Installs K3s (lightweight Kubernetes)
3. ✅ Installs Helm package manager
4. ✅ Installs Cert-Manager (for SSL)
5. ✅ Installs Metrics Server (for HPA)
6. ✅ Creates `smsly-workloads` namespace with resource quotas
7. ✅ Outputs kubeconfig for Control Plane connection

### Connect Worker to Control Plane

After installation, the script outputs a kubeconfig. Copy it to your Control Plane:

```bash
# On Control Plane server
cd /opt/smsly-hosting

# Save the kubeconfig
cat > kubeconfig <<EOF
# Paste the kubeconfig from worker node here
EOF

# Add volume mount to docker-compose.yml
# volumes:
#   - ./kubeconfig:/root/.kube/config:ro

# Restart services
docker compose restart backend celery
```

## 4. Post-Installation

### Access Dashboard

- **URL**: `https://your-domain.com`
- **API**: `https://your-domain.com/api/v1/`
- **Admin**: `https://your-domain.com/api/admin/`

### Create First Service

1. Log in to the dashboard
2. Click "Create New Service"
3. Enter your GitHub repository URL
4. Click "Deploy"

### Verify SMSLY Integration

If you enabled SMSLY integration, test it:

```bash
# On Control Plane
docker compose exec backend python manage.py shell
>>> from services.smsly_client import smsly_client
>>> smsly_client.send_sms_sync('+1234567890', 'Test alert!', 'SMSLYHost')
```

## 5. Configuration Reference

### Environment Variables

All configuration is in `/opt/smsly-hosting/.env`:

```bash
# Core (required)
SECRET_KEY=<auto-generated>
FIELD_ENCRYPTION_KEY=<auto-generated>

# Domain
ALLOWED_HOSTS=your-domain.com,localhost
CSRF_TRUSTED_ORIGINS=https://your-domain.com

# SMSLY Integration
SMSLY_INTERNAL_API_KEY=<your-key>
ALERT_PHONE_NUMBER=+1234567890

# Registry (for pushing images)
CONTAINER_REGISTRY_URL=registry.example.com
REGISTRY_USER=<username>
REGISTRY_PASSWORD=<password>
```

## 6. Troubleshooting

### Services Not Starting

```bash
cd /opt/smsly-hosting
docker compose logs -f
```

### SSL Certificate Issues

```bash
# Retry SSL
sudo certbot --nginx -d your-domain.com
```

### Database Connection Failed

```bash
# Check if db is running
docker compose ps
docker compose logs db
```

### Worker Not Connecting

```bash
# On worker: verify K3s is running
kubectl get nodes

# On control plane: check kubeconfig
docker compose exec backend kubectl get nodes
```

## 7. Upgrading

```bash
cd /opt/smsly-hosting

# Pull latest
git pull origin main

# Rebuild and restart
docker compose down
docker compose up -d --build

# Run migrations
docker compose exec backend python manage.py migrate
```

## 8. Backup & Restore

### Backup Database

```bash
docker compose exec db pg_dump -U postgres smsly_hosting > backup.sql
```

### Restore Database

```bash
cat backup.sql | docker compose exec -T db psql -U postgres smsly_hosting
```
