# Verification Scripts

This directory contains automated verification scripts used to validate various aspects of the system.

- `verify_all_pages.py`: Checks availability of all frontend pages.
- `verify_branding.py`: Validates UI elements and branding consistency.
- `verify_fixes.py`: Verifies specific bug fixes.
- `verify_new_ui.py`: Checks the new UI components.
- `verify_webhook_logic.py`: Tests the GitHub webhook logic.
